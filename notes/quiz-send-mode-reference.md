Opções disponíveis:

1. Único — Para uma avaliação pontual. Você definirá se o envio será imediato ou agendado para uma data específica.
2. Diário — Escolha um ou mais dias para o envio se repetir toda semana (ex: toda segunda, quarta e sexta).

4. Manual — Adicione um ou mais envios em datas específicas, sem seguir uma regra fixa de repetição.
5. Aberto — Questionário sempre disponível para resposta, sem configurações de envio e recorrência.
